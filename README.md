# Python Data Science & AI Foundations

This repository contains a progressive collection of Python scripts demonstrating foundational to advanced skills in data analysis, data wrangling, linear algebra, and data preprocessing for Machine Learning.

## Project Structure & Progression

* **`01_python_fundamentals.py`**: Covers core Python programming logic, including control flows, iterative loops, functions, and standard data structures.
* **`02_inventory_management_cli.py`**: A terminal-based Inventory Management System utilizing Python dictionaries and sets.
* **`03_math_and_stats_toolkit.py`**: Implements core Linear Algebra operations (vector/matrix addition, multiplication, transpose) and statistical metrics (variance, standard deviation, Pearson correlation) from scratch.
* **`04_numpy_pandas_basics.py`**: Introduces matrix transformations via `NumPy` and foundational Exploratory Data Analysis (EDA) on the Titanic dataset using `Pandas`.
* **`05_data_wrangling_merging.py`**: Focuses on relational data operations, including complex DataFrame merging (Inner, Left, Right, Outer joins) and group-by aggregations.
* **`06_exploratory_data_analysis.py`**: Showcases advanced data visualization strategies using `Matplotlib` and `Seaborn` (heatmaps, boxplots, pairplots) to extract insights.
* **`07_data_preprocessing_pipeline.py`**: Integrates `Scikit-learn` for feature scaling (MinMaxScaler, StandardScaler) and handles categorical encoding (One-Hot Encoding) to prepare data for ML models.
* **`08_advanced_data_cleaning.py`**: A robust data cleaning pipeline designed to handle messy data. Involves standardizing inconsistent text casing, removing duplicates, and merging external mapping tables to output a clean, modeling-ready CSV dataset.

## Technologies Used
* **Languages:** Python 3.x
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
